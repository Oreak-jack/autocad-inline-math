# 安装与自动下载更新

适用 Windows x64、完整版 AutoCAD 2025/2026。默认当前用户安装，不需要为了安装器主动以管理员运行。自选无写入权限的目录会报错，请改选可写目录。

## 第一次安装

1. 下载并**完整解压**最新安装包，不要在 ZIP 预览窗口里运行。
2. 双击根目录的 **安装或更新.cmd**。
3. 默认位置是 `%APPDATA%\Autodesk\ApplicationPlugins`。需要其他位置时点击「浏览」选择上级文件夹；安装器会创建专用的 `CadMath03.bundle`，不会把文件散放进所选目录。
4. 点击「下载并安装 / 更新」，自动获取 GitHub 最新正式版并校验。网络不可用时，可点「使用随包版本（离线）」。
5. 如果 CAD 正在运行，先保存图纸、关闭所有 CAD 窗口，再点「CAD 已关闭，继续安装」。安装器不会代替你保存或强制关闭 CAD。
6. 安装完成后重新打开 CAD，输入 `CM3STATUS` 确认版本。以后从桌面 **CAD 四则运算 - 检查更新** 进入更新窗口。

首次启动可能出现 Windows 或 CAD 的未签名软件确认提示。请核对来自本仓库；安装器不会永久修改 PowerShell 执行策略或关闭 CAD 的安全加载。组织策略禁止脚本执行时，需要由管理员按该组织流程部署。

## 下载以后会发生什么

自动校验 SHA-256 → 等待 CAD 关闭 → 备份旧版和相关设置 → 替换插件 → 完成。

**无需打开下载文件夹、手工解压覆盖或重新添加 LSP。** 安装阶段发生可捕获错误时，安装器尝试恢复原来的文件和设置；如果恢复也失败，会显示备份位置，不会声称安装成功。

更新窗口自动下载最新正式版，忽略预发布。不是后台定时更新：用户点击桌面入口发起；首次选定的位置会被记住，后续更新不再改路径。不自动重启 CAD，也不自动打开图纸。

## 路径与旧版迁移

- 默认目录通过 bundle 自动加载。自选目录通过当前用户 AutoCAD 注册信息加载，不需要用户配置 LSP。
- 安装器仅将本插件 DLL 所在目录加入已有配置的可信路径，不修改 `SECURELOAD`、`DEMANDLOAD` 或 `APPAUTOLOAD`。如果自动加载被禁用，需要按自己的 CAD 管理要求启用。
- 自动识别此项目提供的 `CadMath03-Local-Startup.lsp` / `CadMath03-Startup.lsp` 启动组条目，并迁移为新加载方式。其他 LSP 条目保持不变；旧 LSP 文件本身保留。
- 同名但内容不属于本项目的 LSP 不会自动移除；其他旧测试插件或用户自编加载脚本需要自行处理。
- 首次安装前，需在同一个 Windows 账户下至少运行一次 AutoCAD，以创建用户配置。以后新装另一个 CAD 版本或创建新配置时，重新运行安装器即可登记。
- 安装记录、管理器和设置备份位于 `%LOCALAPPDATA%\CadMathInlineMath`。旧插件备份保存在原安装目录旁的 `.CadMath-backup-*` 文件夹，不自动删除。
- 校验文件与安装包来自同一 GitHub 发布页，能检测下载损坏，但不等于独立数字签名。
