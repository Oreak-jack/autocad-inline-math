# v0.3.1 — LEN / LENGTHEN

上一版命令白名单遗漏了 `LENGTHEN`，因此 LEN 的长度输入不会进入表达式处理。v0.3.1 增加该命令，继续只在数值或点输入提示时转换；选对象和选项输入仍交给 CAD。

底部命令栏使用方式不变：进入 LEN，选择需要的长度模式，在提示输入长度时输入 `100-5`。空格/回车沿用原处理方式。如果连续空格调出的默认模式不是你需要的模式，请明确选择「全部/总长度（Total）」或「增量（Delta）」。表达式只决定数值，长度模式仍由 CAD 决定。

## 原生验证步骤（尚未实测）

更新后先重启 CAD，输入 `CM3STATUS`，确认显示 `0.3.1`。在新图中关闭光标旁动态输入，每项使用一条新画的长度 100 的直线：

1. `_.LENGTHEN` → `_Total` → `100-5` → 选择直线靠近要调整的一端 → Esc。预期总长 95。
2. `_.LENGTHEN` → `_Delta` → `10+5` → 选择直线端部 → Esc。预期总长 115。
3. `_.LENGTHEN` → `_Delta` → `-5/2` → 选择直线端部 → Esc。预期总长 97.5。
4. `_.LENGTHEN` → `_Percent` → `50+25` → 选择直线端部 → Esc。预期总长 75。
5. 测试自己常用的 `LEN` 加连续空格流程；确认当前提示确实要求输入长度，再输入 `(50-10)/2`，核对当前模式下的结果。
6. 对照测试普通数字、鼠标选择、Esc、撤销；输入 `1/0` 应被拦截，可退格修改或 Esc 取消。

用特性面板测量实际长度；如果刚画的测试直线仍是最后图元，也可使用 `CM3CHECK`。日志中的 `replacement_requested ... command=LENGTHEN` 只说明请求替换，不是最终图元结果的证明。
